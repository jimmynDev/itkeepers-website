# ITKeepers Website V1

A fast, prerendered Astro redesign built around **“Your IT person is a team.”** It preserves the existing ITKeepers logo and navy/cyan palette while making the operating model the main differentiator.

## Run locally
```
npm install
npm run dev
npm run build
```

## Routes
Home; Managed IT; Microsoft & Cloud; Cybersecurity; Networks & Infrastructure; Backup & Recovery; How We Work; Our Team; Contact; Privacy.

## Design rules
Editorial hierarchy, real operational explanations, no fabricated testimonials or counters, no fake live monitoring, and no stock employees. The current logo is referenced from the owned ITKeepers asset URL and should be copied into the repo before production deployment.
